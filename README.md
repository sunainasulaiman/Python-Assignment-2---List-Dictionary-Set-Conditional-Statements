# Python-Assignment-2---List-Dictionary-Set-Conditional-Statements
This repository contains solutions for Python Fundamentals Assignment 2, covering basic data structures (Lists, Dictionaries, and Sets) as well as user input handling with Operators & Conditional Statements (if, elif, else).

This assignment demonstrates core Python concepts:

Manipulating lists using standard methods (append, insert, remove, pop, extend, sort, max, min, sum).

Managing key-value pairs in dictionaries (keys(), values(), items()).

Understanding unique properties of sets (uniqueness, immutability of elements, set logic like union and intersection).

Implementing control flow structures based on numeric user inputs.
